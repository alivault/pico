A web workspace for your Pi coding agents.

Pico runs on your machine and keeps every Pi session safe. Runs continue after a crash or restart. Git, files, terminals, and agent tools are all in one app.

What Pico does

Durable sessions

All sessions live in one SQLite database. Runs continue after a crash or restart. Tools with side effects do not run twice.

A full workspace

See Git changes and diffs, browse files with syntax highlighting, and open terminals next to the agent.

Rich agent tools

Todo lists, questions, background jobs, terminals, child sessions in Git worktrees, browser automation, web access, and MCP.

Tool profiles

Pick full, builder, researcher, reviewer, or read-only, or make your own. Child sessions get a profile from their parent and a bash guard.

Many machines

Add other computers over SSH or Tailscale. Their sessions show in the same sidebar and keep running on their own machine.

Works with Pi

Pico uses your Pi skills, prompt templates, project instructions, and credentials.

See it work

One agent starts two child sessions, each in its own Git worktree. When both are done, it merges their branches and runs the tests.

On your phone, too

Pico works well on small screens. Connect over Tailscale and check on your agents from anywhere.

Pico has no login. Anyone who can reach it can run commands as your user. Keep it on a private network. Never expose it to the public internet.

Get started

You need Node.js 22.19 or later and Git. Install Pico from npm:

npm install -g @alivault/pico
pico-app

Pico starts and opens http://127.0.0.1:3141 in your browser. Add provider credentials in Pico, or use the ones in ~/.pi/agent/auth.json.

To try it without a global install:

npx @alivault/pico

Useful commands:

pico-app status       # is Pico running?
pico-app stop --wait  # stop after active runs finish
pico-app import-pi    # import old Pi sessions (stop Pico first)
pico-app machine add ali@workbox  # show the sessions of another computer
pico-app --help

Your data is in ~/.pico. To build from source, see the README.
