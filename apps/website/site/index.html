A web workspace for your Pi coding agents.

Smith runs on your machine and keeps every Pi agent safe. Turns continue after a crash or restart. Git, files, terminals, and agent tools are all in one app.

What Smith does

Durable agents

All agents live in one SQLite database. Turns continue after a crash or restart. Tools with side effects do not run twice.

A full workspace

See Git changes and diffs, browse files with syntax highlighting, and open terminals next to the agent.

Rich agent tools

Todo lists, questions, background jobs, terminals, subagents in Git worktrees, browser automation, web access, and MCP.

Tool profiles

Pick full, builder, researcher, reviewer, or read-only, or make your own. Subagents get a profile from their parent and a bash guard.

Many machines

Add other computers over SSH or Tailscale. Their agents show in the same sidebar and keep running on their own machine.

Search past work

Find any message of any agent, also on other machines. Agents can search past work too.

Scripts and the command line

Start, message, and wait for agents with smith agent. Exit codes tell a script if the agent is done, failed, or needs you.

An MCP server

Claude Code, Codex, and other MCP clients can start, message, search, and wait for Smith agents.

Works with Pi

Smith uses your Pi skills, prompt templates, project instructions, and credentials.

See it work

One agent starts two subagents, each in its own Git worktree. When both are done, it merges their branches and runs the tests.

On your phone, too

Smith works well on small screens. Connect over Tailscale and check on your agents from anywhere.

Smith has no login. Anyone who can reach it can run commands as your user. Keep it on a private network. Never expose it to the public internet.

Get started

You need Node.js 22.19 or later and Git. Install Smith from npm:

npm install -g @alivault/smith
smith

Smith starts and opens http://127.0.0.1:3141 in your browser. Add provider credentials in Smith, or use the ones in ~/.pi/agent/auth.json.

To try it without a global install:

npx @alivault/smith

Useful commands:

smith serve --detach  # run in the background
smith status       # is Smith running?
smith stop --wait  # stop after active turns finish
smith update       # install the newest version and restart
smith restart      # restart at once; turns continue
smith import-pi    # import Pi sessions as agents (stop Smith first)
smith machine add ali@workbox  # show the agents of another computer
smith agent start . "Fix the flaky test" --wait  # run an agent from a script
smith agent search "websocket"  # search the messages of all agents
smith mcp          # add Smith to Claude Code or Codex
smith --help

Your data is in ~/.smith. To build from source, see the README.
